# Clarity – Carbon Activity Tracking and Emission Calculation System

Clarity is a web-based project that helps users track their daily activities and calculate the carbon emissions generated from them.

## Features
- Add and manage user activities
- Store activity data in a MySQL database
- Calculate carbon emissions using emission factors
- Generate rule-based insights
- View activity and emission details on a dashboard

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- XAMPP

## Database
The database structure is available in `clarity_db (1).sql`.

## How to Run Locally
1. Install XAMPP.
2. Copy the project folder into `htdocs`.
3. Start Apache and MySQL.
4. Import the SQL file into phpMyAdmin.
5. Open the project in your browser using `http://localhost/clarity/`.
